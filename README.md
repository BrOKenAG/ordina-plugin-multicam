# ordina-plugin-multicam

**Multicam Tools** 的发布仓库：只存放已签名清单与不可变 Release 资产。

插件源码、安装逻辑与客户端在主仓库 [BrOKenAG/ordina-releases](https://github.com/BrOKenAG/ordina-releases)，由 ordina 的插件管理安装和更新。

- `manifest.json` — 插件清单，由主仓库的 `scripts/publish_plugin.py` 生成并签名，请勿手工修改。
- Releases — 每个版本一个不可变资产，供清单引用。

清单地址：<https://brokenag.github.io/ordina-plugin-multicam/manifest.json>

发布方法见主仓库的[发布说明](https://github.com/BrOKenAG/ordina-releases/blob/main/docs/releases.md)。
